# Rich-content Ozon: регулируемые ножки-опоры

Готовый комплект Alistek, 6 баннеров 1440×720 PNG и richcontent_ozon.json.

Размеры ассортимента: М6×30, М6×90, М8×35, М10×40, М10×85.

Важное уточнение: отдельного исходного фото М10×85 в предоставленном наборе нет. На баннере М10 показывается фото М10×40, размер М10×85 указан текстом без подмены товара.

Вставляйте содержимое richcontent_ozon.json в редактор JSON Ozon. Проверка фактического сохранения в личном кабинете не проводилась.
