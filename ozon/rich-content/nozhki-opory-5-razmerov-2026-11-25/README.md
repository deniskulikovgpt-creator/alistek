# Rich-content Ozon: регулируемые ножки-опоры

Исправленный комплект Alistek: 6 баннеров по 1440×720 PNG и `richcontent_ozon.json`.

**Актуальные размеры:** М6×30, М6×90, М8×35, М10×55, М10×80.

Исправлены только текстовые обозначения в баннерах 02 и 05; изображения товаров, логотип, фон и габариты сохранены. На баннере 05 в подписи к фото указано М10×55; для М10×80 отдельное фото не использовано.

Обновлённый JSON ссылается на новые имена файлов с исправленными размерами, чтобы исключить устаревшие версии из кеша. Старые имена PNG тоже заменены на исправленное содержимое для обратной совместимости.

Вставьте содержимое `richcontent_ozon.json` в JSON-редактор Ozon. Успешное сохранение в личном кабинете Ozon не проверено.
